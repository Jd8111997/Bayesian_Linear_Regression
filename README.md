# Bayesian_Linear_Regression
Implementation of Bayesian Linear Regression.

## 1) Task 1 :- Experiments with Regularization parameter.
In first task, the analysis of the regularization parameter is done with respect to the Mean Squared Error for each dataset.

In Task 2 and Task 3, I did the analysis of two model selection methods : Cross validation and Bayesian Model Selection with respect to the MSE.
