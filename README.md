# Bayesian_Linear_Regression
Implementation of Bayesian Linear Regression from scratch.     
In Task 1, An Experiment has been conducted to study the functional relationship of MSE with respect to the Regularization parameter(in a range 0 - 150)    
In Task 2 and Task 3, I did the analysis of two model selection methods : Cross validation and Bayesian Model Selection with respect to the MSE.
